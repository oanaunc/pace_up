# Pace Up

iOS activity tracking app with HealthKit integration, live route recording, achievements, and home-screen widgets.

## Requirements

- Xcode 15+
- iOS 17+
- Apple Developer account (for HealthKit, location, and widgets on device)

## Open the project

```bash
open PaceUp/PaceUp.xcodeproj
```

Select the **PaceUp** scheme, pick a simulator or device, then Run.
